# Attribution and data sources

MMM-WeatherCards contains custom module code extracted into a standalone
package. MagicMirror² (https://github.com/MagicMirrorOrg/MagicMirror) is a
separate MIT-licensed runtime dependency, not bundled source. The package MIT
license covers its code; it does not grant rights to third-party content
supplied by users or external APIs. Examples are synthetic. Screenshots use the
system's font/emoji renderer; no font or emoji image collection is bundled.
Inline drawings are retained from the custom source. No upstream module patch or
production image collection is included.

Weather and air-quality services: https://open-meteo.com/ . A visible Open-Meteo
credit is included in the rendered card. Open-Meteo documents data licensing and
attribution at https://open-meteo.com/en/terms . Preserve attribution when
sharing weather output. Confirm current endpoint access terms, quotas, upstream
air-quality credits and commercial-use requirements for your use case. API
service access and underlying data licensing are separate from this package's
MIT code license. Live terms and endpoints were not independently verified
during offline extraction.
